# The World Today — Sunday 22 November 2026, in their own words

One image that sums up the world's news of Sunday 22 November 2026, led by what
the day's key voices actually said. `main.py` (Python 3, stdlib only) copies
`entry.png` to `/output/entry.png` and verifies size + sha256; run it twice and
the bytes are identical.
